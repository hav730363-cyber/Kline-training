K线训练 Windows 便携版 v1.9.7

使用方法
1. 解压 K线训练-Windows-便携版.zip 到一个普通文件夹。
2. 双击 K线训练-Windows-便携版.exe。
3. 程序会自动打开独立窗口，不需要安装 Python 或手动启动 localhost 服务；BaoStock 依赖已打包在本地服务中。
4. 退出窗口即可结束本次本地服务。

联网取数
程序默认按需通过自动多源路由获取真实前复权数据：日线 BaoStock → Tushare Pro → 通达信 TQServer → AKShare，5 分钟分时通达信 → Tushare Pro → BaoStock → AKShare。未配置、超时、空数据或失败时会进入下一来源，全部失败则明确提示；也可以改用 CSV 导入，不会用假数据替代。Tushare Token 和通达信组件需要用户自行配置，凭证不要写入 EXE。

日线分时成交量
- 在日线训练图中双击任意已显示的日 K 线柱，即可打开对应交易日的真实 5 分钟成交量柱状图。
- 弹窗会显示来源、时段数量、获取时间和缓存状态；没有真实数据时会明确提示，不绘制假图。
- 柱体颜色按 5 分钟 K 线方向显示：红色为收盘高于开盘（买方占优），绿色为收盘低于开盘（卖方占优），灰色为平盘；这不是逐笔主动买卖量。
- 裸 K 训练未结束时，弹窗隐藏股票名称和日期，只显示训练序号；训练结束后显示真实信息。

样本采集与严格准入
- “样本采集”按轮次轮换标的，每轮最多120个，已经扫描的标的会保存到本机状态文件，下一轮继续未扫描标的。
- 采集弹窗显示已扫描/总数、成功、失败、进度、当前证券、轮次和剩余数量；失败会继续处理其他标的，点击停止后不再发起新的标的请求。
- 只有220个完整日K，并且220个交易日每天都有严格48根真实5分钟分时，才能审核进入训练库；不完整数据会停留在等待/待补齐状态。
- 候选“重新复核”会弹出实时状态面板，显示阶段、重试次数、耗时和最终结果。同一候选不能重复启动复核。

速度与缓存
- 证券列表、历史日线和分时数据会在本机用户数据目录中缓存，并在下次启动时尝试恢复。
- 单个请求有超时、有限重试和备用源切换；失败原因会显示在页面中。

故障排查
- Windows Defender 首次运行提示时，请确认文件来自你本人保存的压缩包后再选择允许。
- 如果程序启动失败，请把提示截图发回；启动日志位于 Windows 用户数据目录下的 kline-training-desktop\startup.log。
- 便携版是 x64 Windows 版本。
- 已关闭 Chromium 硬件加速，针对部分 Windows 电脑启动访问冲突做了兼容处理。
- “样本采集”会自动获取股票/ETF清单，按轮次扫描最多 120 个未扫描标的，再筛选背景 40 根 + 训练 180 根的候选片段；每种形态每轮最多保留 1 个候选，仍需人工审核。
- 日线候选只有在日线双源复核通过、并完整补采 220 个交易日的真实 5 分钟分时数据后，才进入形态审核；采集面板会显示分时补采进度。
- 点击“样本采集”时会先检查旧版本样本；缺少完整分时的已验证片段会自动补采，补齐前不会继续作为训练片段使用。
- 候选片段操作区提供“重新获取分时”，只重新处理当前片段；成功后恢复训练资格，失败会显示原因。
- 审核驳回会立即删除该候选；审核通过才保留到训练库。
- 分时数据仅适用于日线训练；当前粒度为 5 分钟。路由顺序为通达信 TQServer、Tushare、BaoStock、AKShare、东方财富公开备用、新浪公开备用；只显示严格对应所选日期的真实数据。
- 形态卡片会显示已审核训练片段数量；点击“展开训练片段”可查看每个片段的标的和日期，并直接训练、移出或恢复。

当前版本说明
- 当前发布版本为 v1.9.7。
- 顶部“数据源状态”可以查看来源配置与最近请求结果；默认推荐自动多源路由。
- 缓存目录增加 SQLite 数据库，同时保留 JSON 缓存兼容旧版本。
- 单人训练优先，暂不包含多人 PK。
- 样本是否进入训练库仍需审核。
- 旧版内置样本库仍保留，样本采集新增内容不会自动跳过人工审核。
