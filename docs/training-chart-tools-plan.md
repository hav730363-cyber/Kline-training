# 训练页面画线与联动十字光标实施方案

状态：已实施并完成桌面／手机验收。实施日期：2026-10-04。

本文件记录训练页面功能范围与验收要求；实际实施和验证结果见第7节。交接索引保留实施前的来源背景。

## 1. 目标与范围

保持现有深蓝页面和主图／右栏布局，新增两项能力：

1. 在价格主图标记支撑、压力和平台区间，在主图及成交量、MACD、KDJ副图绘制趋势线。
2. 十字光标自由移动、不吸附；同一竖线贯穿可见主副图，便于对照同一根已显示K线的价量与指标真实数值。

完成标准：画线可编辑、保存、恢复，缩放后仍对准原时点和数值；光标不改变交易时点或成交价；桌面和手机均可操作，图表清晰，原有笔记、交易、波段和复盘保存不受破坏。

不包括：重新设计整页布局、改动交易或指标计算、改动波段划分／样本准入、启动采集、实现复盘教学引擎、接入云端AI、账号或公网部署、重新打包EXE／ZIP、发布GitHub。

## 2. 已确认的交互

### 2.1 主副图画线

| 工具 | 可用区域 | 用途 |
|---|---|---|
| 水平价位线 | 价格主图 | 标支撑、压力或待观察价位 |
| 价位区间 | 价格主图 | 标平台／支撑压力区间的上下沿 |
| 两点趋势线 | 价格主图、成交量、MACD、KDJ | 比较同一时间段的变化方向 |

趋势线首版使用两点线段，不默认无限延长，也不自动选择高低点。副图水平线／区间、自动找支撑压力、角度或背离自动判定不属于本轮范围。

工具栏紧凑排列，提供查看、画线、笔记的清晰模式，以及选择、调整、删除、撤销／重做、显示／隐藏标记。空白处取消选择，取消未完成的绘制不改变既有记录；删除和撤销以可恢复历史表达。

主图标记可选支撑／压力／待观察标签，可附简短理由；副图趋势线可附观察说明。标签只代表用户判断，不能自动变成已验证买卖信号。

每条线属于一个面板，两端不能跨面板连线。切换或隐藏副图只隐藏对应标记，不丢失它们。线和标签裁切在自己的面板内，不遮挡交易股数、铅笔入口、价格轴及波段编号。

### 2.2 不吸附十字光标

- 横纵坐标均随鼠标／触点自由移动，不跳到K线中心、收盘价或指标曲线。
- 竖线沿共享时间轴贯穿当前显示的主图、量能和指标面板；横线只在光标所在面板显示，并按该面板比例换算刻度。
- **光标位置读数与实际数据分开**：横线标为光标价位／光标刻度；数据栏明确标出“对应第N根”，展示最近一根已显示K线的真实数据。处于两根之间时不插值生成OHLC、成交量或KDJ值；距离相等时选左侧一根，结果稳定。
- 图内观察信息显示开、高、低、收、现有口径的涨跌幅、成交量及单位、VOL-MA120／250、MA5／20／60、DIF／DEA／MACD柱、K／D／J。必要时换行或分组，不挤压绘图区；缺失值显示“—”，不显示成0。若缺少前收，不猜测涨跌幅。
- 裸K训练继续隐藏真实标的和日期，以原有匿名根号说明时点；显示身份时才展示日期。隐藏的预热区和未推进的未来K线不得成为观察对象。
- 观察历史只改变图内观察读数；右栏下单、账户和训练推进仍基于原来的当前训练时点。不能把观察历史误写入当前成交条件。
- 桌面悬停查看；触屏在查看模式点按／按住后移动查看，显式退出观察。查看、画线、拖动、笔记之间不得抢同一次手势。

十字光标自由移动不等于指标存在连续中间值。不同面板单位和自动缩放不同，不能以屏幕倾斜角度评价价量是否一致；本轮不生成这种自动结论。

### 2.3 原有操作的兼容

查看模式的观察操作不自动打开笔记。保留明确的铅笔／笔记入口和笔记模式；保留双击查看分时的入口，处理单击与双击的延迟冲突。绘制或编辑线时不得误开分时、笔记，或推进训练。

拖图、滚轮缩放、全景、波段定位／返回总览继续可用；画线期间使用明确模式避免拖动画布。输入笔记时原有空格键防误推进行为继续保留。

## 3. 标记、保存与因果记录

### 3.1 坐标与版本

标记以稳定标识、面板、类型、行情时点和真实价格／指标值存储，不能只保存像素。允许自由端点以时间轴位置记录；它是画线几何坐标，不是新造的行情数据。重绘时使用同一份面板坐标转换。

每次新增、调整、删除、撤销或重做均保留动作时间、当前已推进的训练索引及顺序信息，保留原版本。旧记录没有可靠顺序时标为无法核实，不补造“原计划”。

**画线锚点日期不等于创建时间。** 在当前决策时标过去的平台是正常历史观察；不能仅因锚点较旧就判为事后画线。判断某笔成交前是否已有标记，须依靠创建时可见范围及动作顺序。训练结束／历史复盘里新增的标记明确提示补标，不冒充原决策依据。

### 3.2 草稿、备份及我的复盘

- 沿用现有草稿、训练备份和复盘档案链路，新增可选画线元数据；不改变现有行情、成交、批次扣减、原笔记和 `manualKeyLevels` 的含义。
- 旧版备份缺少画线字段时按空记录恢复；已有手工价位标记仍显示，不能因增加新工具而被清空、覆盖或重复绘制。
- 当前复盘档案采用版本2；优先在现有可选字段兼容范围内实现，不引入新后端接口或数据库迁移。
- 在“我的复盘”可以看到并查看标记历史，复盘补标另存。打开和编辑历史复盘不能改写正在进行的训练。
- 更换标的／开始新训练时保持各局隔离；导入失败不破坏当前草稿。保存失败沿用未同步提示、重试与导出，不伪称保存成功。
- 本轮只让标记成为可保存、可查看的观察依据，不扩展复盘自动建议或规则评分。

## 6. 验收与交付

### 固定案例及无未来信息

- 连续移动两根之间：光标不吸附；横线刻度连续，OHLC和指标始终对应明确的实际K线；验证首尾、中点、空白、隐藏副图、无数据及缺失数值。
- 覆盖J负值、J超100、负MACD、零成交量及不同价格精度；横线按各自轴还原，不混用刻度。零成交量不误判缺失。
- 使用截断到可见时点与完整行情分别计算观察读数，结果一致；观察索引、画线端点交互范围及图轴均不能使用未推进数据。
- 比较使用工具前后的当前索引、现金、可卖股数、下单价、笔记和指标结果；观察和画线本身不能改变它们。

### 交互、保存和既有回归

- 主图水平线／区间／趋势线与各副图趋势线都测试新增、调整、删除、撤销／重做、隐藏；跨图第二端点须拒绝或明确取消。
- 缩放、拖动、全景、尺寸变化和副图切换后坐标不漂移；移到可见范围外的标记保留但不错误绘制。
- 检查同根多笔成交、铅笔、笔记输入、分时双击和训练推进；手机操作无误触和横向溢出。
- 刷新、旧新版备份、未完成绘制、保存失败／重试、结束归档及打开历史复盘；核对旧笔记、价位历史、批次与当前训练完整保留。
