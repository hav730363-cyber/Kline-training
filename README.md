# K线形态训练 App

这是第一阶段的单人日线 MVP 原型，默认使用内置演示行情，也支持导入本地日线 CSV，并可通过本地服务按代码获取真实 A 股或场内 ETF 日线。

## 本地运行

在当前目录执行：

```powershell
python server.py
```

然后打开：<http://localhost:8000>

如果电脑尚未安装 Python，后续可以再安装。当前原型不依赖第三方前端框架；`server.py` 负责静态文件和真实行情的同源代理。

- 响应式电脑/手机页面
- 逐根推进日 K 线
- 收盘价买卖
- 100 股整数倍交易
- A 股 T+1 可卖数量限制
- 分仓、加仓、减仓、清仓
- 买入和卖出快捷仓位：全仓、半仓、三分之一仓、六分之一仓
- 空格键快捷推进下一根 K 线；输入框和按钮获得焦点时不会误触发
- 演示手续费和卖出印花税
- 成交量柱、VOL-MA120、VOL-MA250，以及天量/地量、放量/缩量辅助判断
- MACD 附图（DIF、DEA、红绿柱）和 KDJ 附图（K、D、J 三线）
- 主图右侧显示可开关的估算筹码峰，并给出主峰、平均成本、获利比例和 70% 筹码区间
- MA5/20/60 价格均线
- K 线上显示交易标记
- 交易记录、现金、持仓、浮盈亏和收益率
- 裸 K 隐藏标的名称和日期
- 导入本地日线 CSV 并进行基础数据校验
- 输入 6 位代码获取真实前复权日线，并显示数据源、数量和获取时间
- 自用测试用户名登录；用户名仅保存于当前浏览器
- 对真实行情或本地 CSV 扫描候选底部片段，显示候选形态、时间区间、底部逻辑评分和初筛置信度
- 候选片段支持采用其形态标签；规则引擎在完成回测前不会把真实样本自动放入正式训练库
- 候选片段支持审核通过、驳回和载入为独立训练区间
- 依据用户提供的 5 张参考图建立 40 个形态模板
- 40 个形态名称旁均配有对应的简化走势示意图
- 样本库与训练库切换
- 按形态类型和名称筛选
- 随机选择形态知识模板（只用于学习规则，不改变当前行情）
- 将模板加入或移出训练库，选择结果保存在当前浏览器
- 训练结束后揭晓带标签样本的形态答案，并显示完整走势
- 将典型行情片段收藏到本机训练库并标记为待审核

## CSV 格式

第一行必须包含以下字段，字段顺序不限：

```text
日期,开盘,最高,最低,收盘,成交量
2025-01-02,10.00,10.30,9.90,10.20,1234567
```

也支持英文字段 `date,open,high,low,close,volume`。至少导入 70 根有效日线，导入后当前训练会自动重置。

筹码峰采用日线价格区间、成交量和时间衰减进行近似计算。缺少真实换手率、流通盘变化和券商专有算法时，它只能用于形态训练中的相对观察，不能视为真实投资者持仓成本分布。

真实行情按钮当前按需获取前复权日线，不会持续后台请求。数据源为服务端代理的 Tencent Finance 接口，接口可能受网络、上游调整或服务条款影响；正式部署前应替换为有明确授权和稳定 SLA 的数据服务，并增加每日收盘后的定时更新。
