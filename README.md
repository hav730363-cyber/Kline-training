# K线形态训练 App

这是第一阶段的单人日线 MVP 原型，必须先载入真实行情或导入 CSV 才能训练；可通过本地服务按代码获取真实 A 股或场内 ETF 行情。当前桌面发布版本为 v1.9.8，包含图表画线、长按平移和联动十字光标。

## 本地运行

在当前目录执行：

```powershell
python -m pip install -r requirements.txt
python server.py
```

然后打开：<http://localhost:8000>

如果电脑尚未安装 Python，后续可以再安装。当前原型不依赖第三方前端框架；`server.py` 负责静态文件和真实行情的同源代理。

## 分享给别人在线使用

仅把源码放到 GitHub 不会产生可直接打开的网页地址。本项目已包含 Render Web Service 配置；将仓库连接到 Render 并完成部署后，可把 Render 提供的网址分享给他人。具体步骤和当前试用边界见[公网部署说明](公网部署说明.md)。训练记录保存在每位使用者自己的浏览器中，目前没有账号系统或多人数据同步。

## CSV 格式

第一行必须包含以下字段，字段顺序不限：

```text
日期,开盘,最高,最低,收盘,成交量
2025-01-02,10.00,10.30,9.90,10.20,1234567
```

也支持英文字段 `date,open,high,low,close,volume`。至少导入 70 根有效日线，导入后当前训练会自动重置。

筹码峰采用日线价格区间、成交量和时间衰减进行近似计算。缺少真实换手率、流通盘变化和券商专有算法时，它只能用于形态训练中的相对观察，不能视为真实投资者持仓成本分布。

真实行情按钮默认按多源路由获取前复权行情；任一来源失败都会进入下一来源，全部失败时明确提示，不会用演示或随机数据替代。Tushare 需要通过环境变量 `TUSHARE_TOKEN` 配置 Token，通达信需要官方 TQServer 组件和权限，AKShare 需要单独安装；凭证不写入前端、EXE 或 GitHub。证券列表、历史日线和分时数据会写入本机用户缓存目录，缓存记录数据源、复权方式和获取时间。分时颜色是开收盘方向的买卖强弱代理，不等同于交易所逐笔主动买卖量。样本采集仍可能受网络、上游调整、频率限制或服务条款影响；正式公开前应确认数据源授权和稳定性，并增加每日收盘后的定时更新。
